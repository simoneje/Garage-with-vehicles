# Garage Management System

## Overview

This project is a console-based Garage Management System written in C#. The application was built as part of an Object-Oriented Programming and Collections assignment with a strong focus on:

* Inheritance
* Polymorphism
* Encapsulation
* Collections and arrays
* Console UI design
* Search and filtering logic

The system simulates a garage where different types of vehicles can be parked, removed, searched, and listed.

---

# Assignment Goals

The purpose of the assignment is to practice:

* Building object-oriented systems using inheritance and base classes
* Working with collections without relying on generic lists for internal storage
* Designing reusable and maintainable code
* Handling user input and validation
* Implementing search and filtering functionality

The application stores all vehicles in a custom garage structure backed by an array of `Vehicle` references.

# Features

## Vehicle Hierarchy

The application uses a base class called `Vehicle` with several subclasses:

* Car
* Boat
* Bus
* Motorcycle
* Airplane

Each subclass inherits common properties from `Vehicle` and adds its own specialized properties.

# Technical Concepts Used

## Inheritance

All vehicle types inherit from the `Vehicle` base class.

## Polymorphism

Vehicles are stored as:

```csharp
Vehicle
```

while still behaving as their real subclass types.

## Method Overriding

Each vehicle overrides:

```csharp
ToString()
```

for custom formatted output.

## Arrays as Collections

The garage stores vehicles using arrays instead of generic lists.

## Dynamic Filtering

Search logic supports optional filtering criteria using nullable values.
